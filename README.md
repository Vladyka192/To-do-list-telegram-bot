<h1>To-do-list-telegram-bot</h1>

Мой учебный проект — Telegram-бот для управления задачами и напоминаниями.

<h2>Функции бота:</h2>
  <ul>
  <li>создавать задачи;</li>
  <li>просматривать задачи;</li>
  <li>изменять и удалять их;</li>
  <li>менять статус задачи;</li>
  <li>устанавливать приоритет;</li>
  <li>указывать дату выполнения;</li>
  <li>добавлять описание.</li>
  </ul>

<h2>NLP</h2>
<p>Одна из основных частей проекта — возможность создавать задачи обычным текстом, а не заполнять каждое поле отдельно.</p>
<p>Например, можно написать:</p>
<p>Сделать домашнее задание завтра в 18:00</p>
<h3>Бот пытается самостоятельно определить:</h3>
<ul>
  <li>название задачи;</li>
  <li>дату;</li>
  <li>время.</li>
</ul>
<h3>Также реализовано определение приоритета по тексту.</h3> Например:

Срочно закончить отчет

Бот может определить, что задача имеет высокий приоритет.

Для обработки дат и времени используется библиотека <b>dateparser</b>, а остальная обработка текста реализована самостоятельно.


<h2>Основной стек проекта:</h2>

<p><b>aiogram 3</b> — работа с Telegram Bot API</p>
<p><b>PostgreSQL</b> — база данных</p>
<p><b>SQLAlchemy</b> — работа с базой данных</p>
<p><b>asyncpg</b> — асинхронное подключение к PostgreSQL</p>
<p><b>Pydantic</b> — проверка и валидация данных</p>
<p><b>dateparser</b> — определение дат и времени из текста</p>
<p><b>python-dotenv</b> — работа с переменными окружения</p>

<h2>Установка</h3>
Для запуска проекта понадобится Python и PostgreSQL.

<h3>Сначала клонируйте репозиторий:</h3>
git clone https://github.com/Vladyka192/To-do-list-telegram-bot.git
cd To-do-list-telegram-bot
<h3>Создайте виртуальное окружение:</h3>
python -m venv venv
<h4>Windows:</h4>
.\venv\Scripts\Activate.ps1
<h4>Linux/macOS:</h4>
source venv/bin/activate
<h3>Установка библиотек</h3>
<p>Все необходимые зависимости находятся в requirements.txt.</p>
<h5>Установить их можно одной командой:</h5>
<p>pip install -r requirements.txt</p>

<h3>Настройка .env</h3>
В репозитории находится .env.example — это пример файла с настройками.
Сначала создайте .env на его основе.
<h4>Windows:</h4>
Copy-Item .env.example .env
<h4>Linux/macOS:</h4>
cp .env.example .env

<h3>После этого откройте .env и укажите свои данные.</h3>
<p>BOT_TOKEN=your_telegram_bot_token</p>
<p>DATABASE_URL=postgresql+asyncpg://username:password@localhost:5432/todo_bot</p>

<h2>Запуск</h2>
<p>После установки зависимостей и настройки .env запустите:</p>
<p>python main.py</p>
