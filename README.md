To-do-list-telegram-bot

Мой учебный проект — Telegram-бот для управления задачами и напоминаниями.

Функции бота:
  создавать задачи;
  просматривать задачи;
  изменять и удалять их;
  менять статус задачи;
  устанавливать приоритет;
  указывать дату выполнения;
  добавлять описание.

NLP
Одна из основных частей проекта — возможность создавать задачи обычным текстом, а не заполнять каждое поле отдельно.
Например, можно написать:
Сделать домашнее задание завтра в 18:00
Бот пытается самостоятельно определить:

название задачи;
дату;
время.

Также реализовано определение приоритета по тексту. Например:

Срочно закончить отчет

Бот может определить, что задача имеет высокий приоритет.

Для обработки дат и времени используется библиотека dateparser, а остальная обработка текста реализована самостоятельно.

Напоминания

Для задач можно создавать напоминания.

Например:

Напомни мне сделать домашнее задание завтра в 18:00


Основной стек проекта:

Python
aiogram 3 — работа с Telegram Bot API
PostgreSQL — база данных
SQLAlchemy — работа с базой данных
asyncpg — асинхронное подключение к PostgreSQL
Pydantic — проверка и валидация данных
dateparser — определение дат и времени из текста
python-dotenv — работа с переменными окружения

Установка
Для запуска проекта понадобится Python и PostgreSQL.

Сначала клонируйте репозиторий:
git clone https://github.com/Vladyka192/To-do-list-telegram-bot.git
cd To-do-list-telegram-bot
Виртуальное окружение
Создайте виртуальное окружение:
python -m venv venv
Windows:
.\venv\Scripts\Activate.ps1
Linux/macOS:
source venv/bin/activate
Установка библиотек
Все необходимые зависимости находятся в requirements.txt.
Установить их можно одной командой:
pip install -r requirements.txt

⚙️ Настройка .env
В репозитории находится .env.example — это пример файла с настройками.
Сначала создайте .env на его основе.
Windows:
Copy-Item .env.example .env
Linux/macOS:
cp .env.example .env

После этого откройте .env и укажите свои данные.
Например:
BOT_TOKEN=your_telegram_bot_token
DATABASE_URL=postgresql+asyncpg://username:password@localhost:5432/todo_bot

Запуск
После установки зависимостей и настройки .env запустите:
python main.py
